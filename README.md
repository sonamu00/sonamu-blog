# 소나무의 기록

GitHub Pages 블로그. 글 원본은 `content/posts`에 마크다운으로 저장됩니다.

Chirpy의 사이드바와 글 카드 구성을 참고한 자체 디자인입니다. 카테고리, 태그, 연도별 아카이브, 본문 검색, 다크 모드, 본문 목차를 제공합니다. `tags: JavaScript, 회고`처럼 쉼표로 태그를 구분합니다. 검색에서 `/` 키를 누르면 검색창으로 이동합니다. 본문의 `##`, `###` 제목은 목차로 자동 생성됩니다.

## 글쓰기와 수정

블로그 상단 **글쓰기** 또는 글 하단 **이 글 수정하기**를 누릅니다. GitHub에서 내용을 편집한 후 **Commit changes → Commit directly to the main branch**로 저장합니다. 파일 이름은 날짜와 영문 소문자, 숫자, 하이픈으로 만듭니다. 같은 날짜에도 서로 다른 파일 이름을 쓰면 여러 글을 게시할 수 있습니다.

메타데이터 예시:

```text
---
title: 오늘 배운 것
date: 2026-09-29
category: 개발
description: 글의 짧은 소개.
---

본문을 작성합니다.
```

`draft: true`를 추가하면 사이트에 노출되지 않습니다. 공개 저장소이므로 초안 원문은 GitHub에서 볼 수 있습니다.

## 옵시디언 기록 발행

기록은 블로그의 **기록** 메뉴에 올라갑니다. 연결할 폴더를 정하면 저장소를 내려받은 폴더에 `records.local.json`을 만듭니다. 폴더 경로는 이 컴퓨터에만 저장됩니다.

```json
{
  "folder": "C:/Notes/MyVault/블로그기록"
}
```

연결한 폴더와 하위 폴더에서 공개할 노트에만 `publish` 체크박스를 추가하고 체크합니다. 마크다운 원본에는 다음과 같이 표시됩니다.

```markdown
---
publish: true
date: 2026-11-17
---

오늘 배운 내용입니다.
```

`title`을 생략하면 파일 이름, `date`를 생략하면 파일 생성 날짜를 사용합니다. `category`, `tags`, `description`은 선택 사항입니다.

1. `npm ci`로 필요한 패키지를 설치합니다.
2. `npm run records:preview`를 실행하고 [로컬 미리보기](http://127.0.0.1:4173/sonamu-blog/records/)에서 발행될 내용을 확인합니다.
3. 미리보기를 `Ctrl+C`로 종료한 뒤 `npm run records:publish`를 실행하면 변경된 기록을 한 커밋으로 GitHub에 올립니다. Git에 작성자 이름과 이메일이 설정되어 있고 `origin`에 푸시할 권한이 있어야 합니다. 변경 사항이 없으면 커밋하지 않습니다.

옵시디언에서 저장한 내용은 다음 발행 때 반영됩니다. 체크를 해제하거나 연결한 폴더 밖으로 옮긴 기록은 다음 발행 후 사이트에서 내려갑니다. 이미 발행된 내용은 공개 Git 이력에 남습니다. 연결한 폴더 내에서 노트 이름이나 위치를 바꾸면 새 주소가 생깁니다.

Windows에서는 `scripts/records-desktop.ps1`을 실행하는 바로가기를 사용할 수 있습니다. 폴더가 설정되지 않았으면 처음 실행할 때 선택할 수 있습니다. 창에서 공개 대상 목록을 확인하고 **발행**을 눌러 반영합니다.

기본 마크다운과 공개 웹 이미지 URL을 지원합니다. 옵시디언 위키 링크와 로컬 첨부 파일은 자동 연결하지 않으며, `%% … %%` 주석은 내보내기 전에 제거합니다.

## 기여 기록

본인 계정과 연결된 이메일로, 포크가 아닌 저장소의 기본 브랜치 main에 커밋해야 합니다. GitHub 웹 편집기에서 본인 계정으로 저장하는 방식을 권장합니다. 변경 사항마다 저장(커밋)해야 하며 단순 타이핑이나 내용이 같은 저장은 새 기여를 만들지 않습니다. 반영에는 최대 24시간이 걸릴 수 있습니다.

https://docs.github.com/en/account-and-profile/reference/profile-contributions-reference

## 설정 및 배포

`site.json`에서 제목과 소개를 수정할 수 있습니다. 저장소 Settings → Pages → Source를 GitHub Actions로 설정합니다. main에 커밋하면 `.github/workflows/pages.yml`이 사이트를 빌드하고 배포합니다. 실패하면 Actions에서 오류를 확인하세요.

```sh
npm ci
npm run build
npm run preview
```

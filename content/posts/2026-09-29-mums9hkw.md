최근 회사에서 개발 업무를 하다가 에이전트와 서버의 통신 과정에 대한 이해가 필요했는데, 관련 네트워크 개념을 어렴풋이 알고는 있어도 어떻게 통신 흐름과 연관되는지 이해하기 어려웠다.
그래서 이번에는 네트워크 통신 과정에서 Source IP와 Destination IP가 어떤 역할을 하고, 목적지가 다른 네트워크에 있을 때 Subnet과 Gateway, Routing이 어떻게 연결되는지 기초부터 다시 정리해보려고 한다.

네트워크 통신에서 패킷을 사용하는데 그 패킷을 보낸 출발지 IP 라고 볼 수 있다. 이 개념을 찾아보게된 계기가 고객사에서 문의가 왔는데 DMZ망이 있는 상태에서 내부망에 있는 서버로 요청을 보냈더니 내부망 서버에서 받은 IP가 내부에서 관리하는 IP가 아닌데 이 IP가 왜 들어오냐는 문의였다.
그래서 찾아봤더니 요청한 클라이언트와 다른 IP 가 보여줄 수 있는 경우가 응용 계층, 네트워크 계층 이렇게 2계층에 각각 존재했다. 
- 응용 계층 (7계층): HTTP 통신을 할 때에는 HTTP 메시지의 헤더에 요청을 보낸 클라이언트 IP 정보가 있다. HTTP `X-Forwarded-For` 등등 클라이언트 IP를 표시하는 여러 헤더가 있다. 7계층 통신이니까 프록시 서버 같은 곳에서 출발지 IP가 바뀔 수 있는데 이 부분은 왜 바뀔 수 있는지는 잘 모르니까 나중에 찾아볼것
- 네트워크 계층 (3계층): 네트워크 패킷에는 이 패킷의 출발지 IP 정보를 Source IP 라고 한다. 3계층 통신이니까 네트워크 장비 설정에 영향을 받을 수 있다. 여기서 게이트웨이로 설정된 장비에 방화벽이나 NAT(내부IP에서 공인IP로 나갈 때 사용) 설정에 따라 출발지 IP가 맨 처음과 달라질 수 있다.

## Subnet
- Subnet이란?
- 같은 네트워크와 다른 네트워크

## Gateway
- Gateway란?
- Gateway가 필요한 이유

## IP Packet과 Ethernet Frame의 관계
- IP Packet은 최종 목적지를 가리킨다
- Ethernet Frame은 현재 구간의 다음 장비를 가리킨다
- Destination IP = 서버, Destination MAC = Gateway가 되는 이유

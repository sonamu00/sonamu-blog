배운 것 기록하는 곳

## 새 글 쓰기

상단의 **글쓰기**를 누르면 GitHub 편집기가 열립니다. GitHub에 로그인한 뒤 제목, 날짜, 분류, 소개를 채우고 본문을 작성하세요. 파일 이름은 `2026-09-29-my-first-post.md`처럼 정하면 됩니다. 같은 이름의 파일이 이미 있다면 다른 이름을 사용하세요.

글을 다 썼으면 **Commit changes**를 누르고 **Commit directly to the main branch**를 선택합니다. 저장 후 자동 배포가 끝나면 블로그에 글이 나타납니다.

## 기존 글 수정하기

글 아래의 **이 글 수정하기**를 누르세요. 내용을 고치고 다시 **Commit changes**로 저장하면 수정 이력도 커밋으로 남습니다.

## 잔디가 남는 조건

본인 GitHub 계정으로 기본 브랜치인 `main`에 저장한 글과 수정 내역은 기여 기록의 대상이 됩니다. 커밋의 이메일은 GitHub 계정에 연결되어 있어야 합니다. GitHub 웹 편집기를 사용하면 로그인한 계정으로 저장할 수 있습니다.

잔디 반영에는 최대 24시간이 걸릴 수 있습니다. 편집기에서 타이핑만 하거나 변경 사항 없이 닫으면 커밋이 생기지 않습니다.

## 마크다운으로 쓰기

`## 소제목`으로 문단을 나누고, **강조할 말**을 표시할 수 있습니다.

```js
const record = '오늘 배운 한 가지';
console.log(record);
```

길고 완벽한 글이 아니어도 괜찮습니다. 다시 찾아볼 수 있는 기록 하나면 충분합니다.

## 1. 학습 배경: Windows 디폴트 공유 삭제 요청
- 회사에서 윈도우 디폴트 공유 삭제 요청 받음
- 디폴트 공유가 뭔지 몰라서 공부 시작

## 2. Windows 파일 공유의 구조
- 네트워크에서 다른 PC의 폴더에 접근하는 기능
- `\\IP\공유이름`

## 3. SMB를 통한 네트워크 파일 공유
- Windows 파일 공유에 SMB 사용
- TCP 445

## 4. Windows 기본 관리 공유
- C$
- ADMIN$
- IPC$

## 5. 기본 관리 공유의 사용 목적
- 원격 관리
- 파일 접근
- 프로그램 배포 등에 사용

## 6. 기본 관리 공유와 보안 위험
- 공유 자체가 취약점은 아님
- 관리자 계정 탈취 시 악용 가능
- Attack Surface 증가

## 7. 불필요한 공유 제거와 접근 제한
- 기본 공유 제거 ≠ 모든 공유 제거
- 필요한 공유는 권한 제한
- 공유 권한 / NTFS 권한
- 최소 권한 원칙

## 8. Windows 11에서 기본 공유 확인 및 설정
- `net share`
- AutoShareWks
- 설정 전후 확인

## 9. Windows Hardening 관점에서 다시 보기
- 불필요한 기능을 줄여 공격 표면 감소

## 10. 정리
- Windows 공유 → SMB → 기본 관리 공유 → 보안 위험 → Hardening
